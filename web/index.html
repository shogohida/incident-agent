incident-agent — live demo

Pick a canned incident, "fire" the alert, and watch the tool gather logs, deploy history, and metrics, then hand them to an LLM for a structured root-cause report. The system prompt and context formatting are copied verbatim from internal/agent/prompt.go. Choose which model answers below: a small model that runs entirely in your browser (WebLLM/WebGPU, free, no key, but rougher output), or the real Claude API with your own key — the same backend production uses.
